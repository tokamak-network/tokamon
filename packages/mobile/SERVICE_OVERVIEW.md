# 걸어서 토큰 받기 - 서비스 소개서

## 📱 서비스 개요

### 한 줄 소개
걸으면서 특정 장소를 방문하면 암호화폐(TON)를 받는 Web3 만보기 애플리케이션

### 서비스 컨셉
"Walk to Earn" + "Visit to Earn" 
- 건강한 걷기 습관 형성
- 실제 매장 방문 유도
- 즉각적인 암호화폐 보상

---

## 🎯 핵심 가치 제안

### 사용자 관점
- ✅ 걷는 것만으로 실제 돈을 벌 수 있음
- ✅ 새로운 장소 발견의 재미
- ✅ 건강 관리 + 수익 창출 동시 달성

### 광고주 관점
- ✅ 온라인 광고의 한계 극복 (실제 방문 유도)
- ✅ 측정 가능한 광고 효과 (ROI 명확)
- ✅ MZ세대 타겟팅에 최적화

## 👥 서비스 참여자

### 1. 일반 사용자 (Walker)
**역할**: 걷기 + 장소 방문 + 토큰 수집

**사용 흐름**:
1. 앱을 켜고 걷기 시작
2. 걸음 수 자동 측정
3. 지도에서 근처 "토큰 스팟" 확인
4. 목표 장소로 이동
5. 50m 이내 접근 시 자동으로 토큰 획득
6. 받은 TON을 지갑에 누적

**획득 가능 수익**:
- 일평균: 0.5 ~ 2 TON (약 2,000 ~ 8,000원)
- 월평균: 15 ~ 60 TON (약 60,000 ~ 240,000원)

### 2. 광고주 (Business Owner)
**역할**: 매장 홍보 + TON 예치 + 고객 유치

**사용 흐름**:
1. 앱에서 "토큰 스팟 생성" 선택
2. 매장 정보 입력 (이름, 설명, 위치)
3. 방문자당 보상 금액 설정 (예: 0.1 TON)
4. 총 예치 금액 결정 (예: 10 TON)
5. TON 결제 후 스팟 활성화
6. 실시간 방문자 수 확인

**예상 효과**:
- 일평균 방문자: 30 ~ 100명
- 전환율: 방문자의 20 ~ 30%가 실제 구매
- 광고 비용: 기존 온라인 광고 대비 30% 절감

## 🛠 핵심 기능 설명

### 1. 만보기 기능

**기능 상세**:
- 실시간 걸음 수 카운팅
- 가속도계 센서 활용
- 임계값 기반 걸음 감지

**표시 정보**:
- 걸음 수
- 이동 거리 (km)
- 소모 칼로리
- 목표 달성률

**목표 설정**:
- 5,000걸음
- 8,000걸음
- 10,000걸음 (기본)
- 12,000걸음
- 15,000걸음

### 2. 토큰 스팟 지도

**지도 표시**:
- 📍 초록색 마커: 활성 스팟 (토큰 있음)
- 📍 회색 마커: 수집 완료 (이미 방문함)
- 📍 빨간색 마커: 토큰 소진 (보상 없음)
- 🔵 파란 원: 수집 가능 범위 (반경 50m)

**스팟 정보**:
- 스팟 이름
- 설명/홍보 메시지
- 보상 금액 (TON)
- 남은 토큰
- 현재 위치에서 거리
- 수집 가능 여부

**지도 기능**:
- 현재 위치 표시
- 실시간 위치 업데이트
- 근처 스팟 필터링
- 스팟까지 경로 안내

### 3. 자동 토큰 수집

**수집 조건**:
- 스팟 중심 50m 이내 접근
- GPS 정확도 30m 이내
- 해당 스팟 미수집 상태
- 스팟에 토큰 잔액 있음

**수집 프로세스**:
```
1. 백그라운드 위치 모니터링
   ↓
2. 근처 스팟 감지 (50m 이내)
   ↓
3. 수집 가능 여부 확인
   ↓
4. 사용자에게 알림
   ↓
5. 사용자 수락
   ↓
6. 스마트 컨트랙트 호출
   ↓
7. TON 전송
   ↓
8. 지갑 잔액 업데이트
```

**보안 기능**:
- 중복 수집 방지
- GPS 위조 감지
- 타임스탬프 검증
- 블록체인 기록

### 4. TON 지갑 연동

**지원 기능**:
- TON 지갑 연결
- 실시간 잔액 조회
- 거래 내역 확인
- QR 코드 주소 표시

**지갑 정보**:
- TON 잔액
- 오늘 획득 금액
- 총 획득 금액
- 수집 횟수
- 생성한 스팟 수

### 5. 스팟 생성 (광고주용)

**입력 정보**:
- 스팟 이름 (필수, 50자 이내)
- 설명 (필수, 200자 이내)
- 위치 (자동 감지 또는 수동 선택)
- 방문자당 보상 (TON)
- 총 예치 금액 (TON)

**자동 계산**:
- 예상 방문자 수 = 예치금액 / 보상금액
- 수수료 (10%)
- 실제 예치 금액

**미리보기**:
- 지도에서 스팟 위치 확인
- 수집 범위 표시
- 예상 효과 시뮬레이션

### 경쟁 분석

| 서비스 | 특징 | 장점 | 단점 |
|--------|------|------|------|
| **Sweatcoin** | 걸으면 자체 코인 | 사용자 많음 | 환전 어려움, 코인 가치 낮음 |
| **StepN** | NFT 운동화 필요 | 높은 보상 | 초기 비용 100만원+, 진입장벽 |
| **캐시워크** | 광고 시청 보상 | 간단함 | 보상 미미 (하루 100원) |
| **이 서비스** | 위치 방문 보상 | 실제 광고 매칭, 즉시 보상 | 초기 광고주 확보 필요 |

### 차별화 전략

**vs Sweatcoin**:
- ❌ Sweatcoin: 자체 코인 (환전 불가)
- ✅ 우리 서비스: TON (실제 환전 가능)

**vs StepN**:
- ❌ StepN: 초기 투자 필요 (NFT 구매)
- ✅ 우리 서비스: 무료 시작

**vs 캐시워크**:
- ❌ 캐시워크: 광고 시청 (귀찮음)
- ✅ 우리 서비스: 자동 수집 (편리함)

**핵심 차별점**:
```
실제 광고주 매칭
= 광고주는 고객 확보
+ 사용자는 높은 보상
+ 플랫폼은 지속가능한 수익
```
