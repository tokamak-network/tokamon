# 점주 기능 명세

## 메뉴 구조

```
[Tokamon 점주 화면]
├── 지갑 연결
├── 잔액 표시 (XX TON) + 충전 버튼
├── 탭
│   ├── 내 스팟 관리
│   ├── 스팟 만들기
│   └── 방문 현황
```

---

## 기능 목록

### 1. 지갑 연결
| 항목 | 내용 |
|------|------|
| 동작 | MetaMask 지갑을 Tokamon에 연결 |
| 입력 | 없음 (MetaMask 팝업에서 승인) |
| 결과 | 지갑 주소 표시, 내부 잔액 조회 |
| 화면 | 로그인 화면 → 메인 화면 전환 |

### 2. TON 충전
| 항목 | 내용 |
|------|------|
| 동작 | 지갑에서 Tokamon 내부 잔액으로 TON 이동 |
| 입력 | 충전할 금액 (TON) |
| 결과 | 내부 잔액 증가 |
| API | POST /api/faucet |
| 컨트랙트 | deposit(user) |

### 3. 스팟 생성
| 항목 | 내용 |
|------|------|
| 동작 | 매장 위치에 리워드 스팟을 등록 |
| 입력 | 아래 표 참조 |
| 결과 | 스팟 활성화, 잔액에서 예치금 차감 |
| API | POST /api/spots |
| 컨트랙트 | createSpot() |

**스팟 생성 입력 필드**:

| 필드 | 타입 | 필수 | 설명 | 예시 |
|------|------|------|------|------|
| 매장 이름 | 문자열 | O | 50자 이내 | "이영희 카페" |
| 설명 | 문자열 | O | 200자 이내 | "아메리카노 50% 할인 중!" |
| 위치 | 좌표 | O | 지도 탭으로 선택 | (37.4979, 127.0276) |
| 1회 방문 보상 | 숫자 | O | TON 단위 | 0.1 |
| 스탬프 목표 | 정수 | O | 보너스까지 필요한 방문 횟수 | 10 |
| 스탬프 보너스 | 숫자 | O | 목표 달성 시 추가 보상 | 2.0 |
| 쿨다운 | 시간 | O | 재방문 최소 간격 | 24시간 |
| 활성 시간 | 시간 범위 | O | 클레임 가능 시간대 | 09:00 ~ 22:00 |
| 총 예치금 | 숫자 | O | 예치할 TON | 30 |

**자동 계산 표시**:
```
1명 단골 비용 = (1회 보상 × 스탬프 목표) + 스탬프 보너스
             = (0.1 × 10) + 2 = 3 TON

예치금으로 가능한 단골 수 = 30 / 3 = 10명
```

### 4. 스팟 재예치
| 항목 | 내용 |
|------|------|
| 동작 | 소진된 스팟에 TON을 추가하여 재활성화 |
| 입력 | 추가 예치 금액 (TON) |
| 조건 | 본인이 생성한 스팟만 가능 |
| 결과 | 스팟 잔액 증가, 비활성→활성 전환 |
| API | POST /api/spots/:id/redeposit |
| 컨트랙트 | redeposit() |

### 5. 내 스팟 관리
| 항목 | 내용 |
|------|------|
| 동작 | 자신이 생성한 스팟 목록 조회 |
| 표시 정보 | 스팟 이름, 남은 TON, 상태(활성/소진), 총 클레임 수 |
| 액션 | 스팟 선택 → 상세 보기 / 재예치 |

### 6. 방문 현황 확인
| 항목 | 내용 |
|------|------|
| 동작 | 스팟별 방문자 통계 조회 |
| 표시 정보 | 아래 참조 |

**표시 정보**:
- 남은 TON / 총 예치 TON
- 총 클레임 횟수
- 스탬프 달성(단골) 고객 수
- 최근 클레임 내역 (시간, 보상 금액)

## 점주 화면 플로우

```
[지갑 연결 화면]
       │
       ↓ 연결 성공
[메인 화면]
  ├── 상단: 잔액 (XX TON) + [충전] 버튼
  │
  ├── [내 스팟] 탭
  │     ├── 스팟 A: 남은 15 TON (활성) → 탭 → 상세/재예치
  │     ├── 스팟 B: 남은 0 TON (소진) → 탭 → 재예치
  │     └── 스팟 없음 → "스팟을 만들어보세요"
  │
  ├── [스팟 만들기] 탭
  │     ├── 지도 (탭하여 위치 선택)
  │     ├── 입력 폼 (이름, 설명, 보상, 스탬프, 쿨다운...)
  │     ├── 자동 계산 (단골 비용, 가능 인원)
  │     └── [생성] 버튼
  │
  └── [방문 현황] 탭
        ├── 스팟별 통계
        └── 최근 클레임 내역
```
