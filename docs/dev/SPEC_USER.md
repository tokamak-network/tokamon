# 사용자(방문자) 기능 명세

## 메뉴 구조

```
[Tokamon 사용자 화면]
├── 지갑 연결
├── 잔액 표시 (XX TON)
├── 탭
│   ├── 지도 (스팟 탐색 + 클레임)
│   ├── 스팟 목록
│   └── 내 기록
```

---

## 기능 목록

### 1. 지갑 연결
| 항목 | 내용 |
|------|------|
| 동작 | MetaMask 지갑을 Tokamon에 연결 |
| 입력 | 없음 (MetaMask 팝업에서 승인) |
| 결과 | 지갑 주소 표시, 잔액 조회 |
| 화면 | 로그인 화면 → 메인 화면 전환 |

### 2. 주변 스팟 탐색 (지도)
| 항목 | 내용 |
|------|------|
| 동작 | GPS 기반으로 주변 스팟을 지도에 표시 |
| 입력 | 없음 (자동 GPS) |
| 결과 | 지도에 스팟 마커 표시 |

**마커 색상**:
| 색상 | 의미 |
|------|------|
| 초록색 | 클레임 가능 (활성 + 쿨다운 완료) |
| 노란색 | 쿨다운 대기 중 (이전에 방문함, 시간 미경과) |
| 회색 | 소진됨 (TON 없음) |

**스팟 탭 시 표시 정보**:
| 정보 | 설명 | 예시 |
|------|------|------|
| 매장 이름 | 점주가 설정한 이름 | "이영희 카페" |
| 설명 | 점주가 설정한 홍보 문구 | "아메리카노 50% 할인!" |
| 1회 보상 | 방문 시 받는 TON | 0.1 TON |
| 스탬프 현황 | 내 스탬프 / 목표 | 3/10 |
| 스탬프 보너스 | 목표 달성 시 추가 보상 | 2 TON |
| 거리 | 현재 위치에서 스팟까지 | 320m |
| 쿨다운 | 다음 클레임까지 남은 시간 | 12시간 30분 |
| 활성 시간 | 클레임 가능 시간대 | 09:00 ~ 22:00 |

### 3. 스팟 목록
| 항목 | 내용 |
|------|------|
| 동작 | 스팟을 리스트 형태로 조회 |
| 정렬 | 거리순 (가까운 순) |
| 표시 | 매장 이름, 보상, 거리, 스탬프 진행률, 상태 |
| 액션 | 탭 → 지도에서 해당 스팟으로 이동 |

**목록 항목 예시**:
```
┌─────────────────────────────────┐
│ 이영희 카페               320m  │
│ 0.1 TON  ⬟⬟⬟⬡⬡⬡⬡⬡⬡⬡ 3/10  │
│ 클레임 가능                     │
├─────────────────────────────────┤
│ 홍길동 피자               500m  │
│ 0.15 TON ⬟⬡⬡⬡⬡ 1/5          │
│ 쿨다운 12시간 남음              │
├─────────────────────────────────┤
│ 강남 치킨                 1.2km │
│ 0.2 TON  ⬡⬡⬡⬡⬡⬡⬡ 0/7       │
│ 첫 방문 보상 대기               │
└─────────────────────────────────┘
```

### 4. 클레임
| 항목 | 내용 |
|------|------|
| 동작 | 스팟 방문 시 TON 수령 |
| 조건 | 50m 이내 + 쿨다운 경과 + 활성 시간 + TON 잔액 있음 |
| 입력 | "클레임" 버튼 탭 |
| 결과 | TON 수령 + 스탬프 증가 |
| API | POST /api/claim/request |
| 컨트랙트 | claim() |

**클레임 결과 화면**:

일반 클레임:
```
┌─────────────────────┐
│   +0.1 TON 획득!    │
│   스탬프 4/10       │
│   잔액: 1.5 TON     │
└─────────────────────┘
```

스탬프 달성:
```
┌──────────────────────────┐
│   스탬프 달성!            │
│   +0.1 TON + 보너스 2 TON │
│   총 2.1 TON 획득!       │
│   스탬프 리셋 (0/10)      │
│   잔액: 5.6 TON          │
└──────────────────────────┘
```

**클레임 실패 메시지**:
| 상황 | 메시지 |
|------|--------|
| 50m 밖 | "너무 멀어요 (XXm). 더 가까이 가주세요" |
| 쿨다운 중 | "다음 클레임까지 XX시간 XX분 남았습니다" |
| 활성 시간 아님 | "활성 시간이 아닙니다 (09:00~22:00)" |
| TON 소진 | "이 스팟의 TON이 소진되었습니다" |
| 비정상 이동 | "비정상적 이동이 감지되었습니다" |

### 5. 클레임 히스토리
| 항목 | 내용 |
|------|------|
| 동작 | 내 클레임 내역 조회 |
| 표시 | 매장 이름, 받은 TON, 보너스 여부, 시각 |
| 정렬 | 최신순 |
| API | GET /api/claim/history |

**히스토리 예시**:
```
┌─────────────────────────────────────┐
│ 총 획득: 5.6 TON                    │
├─────────────────────────────────────┤
│ 이영희 카페  +2.1 TON (보너스 포함)  │
│ 2026-02-07 12:30                    │
├─────────────────────────────────────┤
│ 홍길동 피자  +0.15 TON              │
│ 2026-02-07 12:15                    │
├─────────────────────────────────────┤
│ 이영희 카페  +0.1 TON               │
│ 2026-02-06 12:20                    │
└─────────────────────────────────────┘
```

### 6. 잔액 확인
| 항목 | 내용 |
|------|------|
| 동작 | 현재 TON 잔액 확인 |
| 표시 위치 | 화면 상단 (항상 표시) |
| API | GET /api/faucet/balance |
| 컨트랙트 | getBalance() |

## 사용자 화면 플로우

```
[지갑 연결 화면]
       │
       ↓ 연결 성공
[메인 화면]
  ├── 상단: 잔액 (XX TON)
  │
  ├── [지도] 탭
  │     ├── 현재 위치 (파란 점)
  │     ├── 스팟 마커들 (초록/노랑/회색)
  │     ├── 마커 탭 → 스팟 정보 패널
  │     │     ├── 매장 정보 + 스탬프 현황
  │     │     ├── [클레임] 버튼 (50m 이내 시)
  │     │     └── 쿨다운 카운트다운 (대기 시)
  │     └── 클레임 결과 알림
  │
  ├── [스팟 목록] 탭
  │     ├── 거리순 스팟 리스트
  │     └── 탭 → 지도로 이동
  │
  └── [내 기록] 탭
        ├── 클레임 히스토리
        └── 총 획득 TON
```
