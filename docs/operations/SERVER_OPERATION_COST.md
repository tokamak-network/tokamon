## 4. 인증번호(Verification Code) 발송 비용

### 4.1 모바일 기기 인증 → FCM 푸시 알림

| 항목 | 내용 |
|------|------|
| 서비스 | Firebase Cloud Messaging (FCM) |
| FCM 발송 비용 | **무료** (무제한, 건당 과금 없음) |
| 사용처 | 클레임 인증 코드, 지갑 연결 인증 코드 |
| 발송 시점 | `POST /api/device/request-code`, `POST /api/device/request-link-code` |

**SMS를 사용하지 않습니다.** 모바일 기기에 직접 FCM 푸시로 인증번호를 전송합니다.

### 4.2 텔레그램 인증 → 텔레그램 봇 메시지

| 항목 | 내용 |
|------|------|
| 서비스 | Telegram Bot API |
| 비용 | **무료** (무제한) |
| 사용처 | 클레임 알림, 인증 코드, 지갑 연결 알림 |
| 발송 시점 | `POST /api/telegram/request-code`, 클레임 이벤트 |

### 4.3 인증번호 발송 시 간접 비용 (대량 발송 시 주의)

FCM 푸시와 텔레그램 봇 메시지 자체는 무료이지만, 인증번호 1건 처리 시 다음의 간접 비용이 발생합니다:

**인증번호 1건 처리 흐름:**
1. 클라이언트 API 요청 → **Cloud Functions 호출 1회**
2. 인증코드 DB 저장 → **Firestore 쓰기 1건**
3. FCM 푸시 전송 → **무료**

| 구간 | 무료 한도 | 초과 시 단가 |
|------|----------|-------------|
| FCM 푸시 발송 | **무제한 무료** | - |
| Cloud Functions 호출 | 2,000,000회/월 | $0.40 / 1,000,000회 |
| Firestore 쓰기 (인증코드 저장) | 20,000건/일 | $0.18 / 100,000건 |

**인증번호 발송량별 과금 시점:**

| 일일 인증번호 요청 | Cloud Functions (월간) | Firestore 쓰기 (일간) | 과금 여부 |
|-------------------|----------------------|----------------------|----------|
| 100건 | ~3,000회 | ~100건 | **무료** |
| 1,000건 | ~30,000회 | ~1,000건 | **무료** |
| 10,000건 | ~300,000회 | ~10,000건 | **무료** |
| 20,000건+ | ~600,000회 | ~20,000건+ | **Firestore 쓰기 초과** |
| 66,000건+ | ~2,000,000회+ | 초과 | **둘 다 초과** |

> **참고:** 인증번호의 Firestore 쓰기는 클레임의 Firestore 쓰기(3건/클레임)와 합산됩니다. 예를 들어 일 5,000건 클레임 + 5,000건 인증번호 = 일 20,000건 쓰기로 무료 한도에 도달합니다.

## 8. 메인넷(Thanos) 전환 시 비용 변화

현재 Thanos Sepolia는 가스비가 0에 가까우나, 메인넷 Thanos 전환 시:

1. **가스비 발생**: 실제 TON 가스비가 부과됨
2. **Faucet 기능 미제공**: 메인넷에서는 Faucet 기능을 제공하지 않음
3. **Rate Limit 권장**: 서버 트랜잭션에 Rate Limit 적용 권장
4. **claimManager 계정 잔액 관리**: 가스비 지불을 위한 TON 잔액 유지 필요
